# 《這一站，青春》行銷影展網站

大二行銷影展專題介紹網站，依據《甲四_這一站，青春_期末企劃書》整理，核心場域為臺中驛鐵道文化園區。

## 網站分頁
- `index.html`：首頁與專題主視覺
- `project.html`：專案執行摘要、企劃核心、廣告精神與目標
- `story.html`：故事大綱與臺中文學館、臺中驛場景
- `marketing.html`：目標客群、需求、競爭者、SWOT 與市場定位
- `team.html`：組員名單、分工與文案理念

## 使用技術
HTML5 語意結構、CSS Grid System、RWD、SEO meta、Open Graph 與原生 JavaScript。CSS 分拆於 `css/`；圖片放置於 `images/`；互動程式放置於 `js/`。

## 專案說明
- 主要目標客群：18–24 歲青年與大學生。
- 核心場域：臺中驛鐵道文化園區。
- 核心定位：青春回憶的載體與情感轉運站。
- Slogan：古蹟留下歷史，我們留下足跡。
