# 這一站，青春｜臺中驛鐵道文化園區行銷影展網站

> 古蹟留下歷史，我們留下足跡。

## 一、專題介紹

本專題以《這一站，青春》為主題，聚焦臺中驛鐵道文化園區，透過行銷企劃與故事型短影音，重新連結歷史古蹟與青年日常。

臺中驛鐵道文化園區以第二代臺中火車站為核心，結合舊月台、鐵道設施及周邊歷史建築，並發展展覽、市集、表演、導覽及體驗活動。企劃觀察到，部分 18 至 24 歲青年對傳統古蹟仍有距離感，可能只把園區視為經過或轉乘的地方，未能深入感受其文化與情感價值。

本專題希望打破古蹟沉悶、單調的刻板印象，讓青年看見臺中驛不只是保存歷史的場所，也能成為與朋友同行、探索、體驗及留下回憶的城市文化場域。

## 二、網站設計理念

**核心概念：青春回憶的載體與情感轉運站。**

網站以「車站」與「青春旅程」作為視覺及內容主軸，透過影展介紹、故事大綱、行銷分析及團隊介紹，呈現臺中驛鐵道文化園區的文化特色與情感價值。

視覺以復古車站與青春電影感為方向，使用深墨綠、暖米白及復古金色，搭配留白、細線及影像區塊，營造帶有年代感又容易閱讀的網站體驗。

## 三、目標客群

- **年齡：**18～24 歲青年，包含學生及初入職場者。
- **地理範圍：**以臺中市及中部地區青年為主要溝通對象。
- **生活型態：**可能喜歡與朋友出遊、城市散步、參觀展覽、市集及特色場域。
- **需求特徵：**重視出遊回憶保存與情感儀式感，期待文化參觀更有參與感。
- **企劃觀察：**部分青年對傳統歷史古蹟缺乏主動參訪動機，對市集、拍照、展覽及多元體驗較感興趣。

## 四、網站功能與內容

1. **首頁：**呈現影展主視覺、核心概念、Slogan 及企劃摘要。
2. **影展介紹：**介紹專案執行摘要、個案概述、企劃核心、廣告精神與目標。
3. **故事與場景：**呈現成年女主角翻閱相簿、高中好友走訪臺中文學館與臺中驛、以吊飾紀念並於多年後重逢的故事。
4. **行銷企劃：**整理產業現況、消費需求、競爭者、SWOT、市場區隔、AIO、青年訪談、競爭者評分及市場定位。
5. **製作團隊：**呈現企劃書所列組員姓名、職務及文案理念。

## 六、使用技術

- **HTML5：**建立網站內容與語意化結構。
- **CSS3：**控制色彩、字體、間距及版面。
- **CSS Grid：**建立主要內容與側欄配置。
- **Flexbox：**調整導覽列及元件排列。
- **RWD：**讓網站適應桌機、平板及手機。
- **SEO：**設定網頁標題、描述、關鍵字及社群分享資訊。
- **JavaScript：**控制手機版導覽列展開與收合。
- **Vibe Coding：**運用生成式 AI 協助網站規劃、程式撰寫與除錯。
