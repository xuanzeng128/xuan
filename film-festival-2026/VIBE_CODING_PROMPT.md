# 大二專題｜《這一站，青春》

## 專題依據

本網站依據《甲四_這一站，青春_期末企劃書》製作。企劃以臺中驛鐵道文化園區為核心，主要目標客群為 18 至 24 歲青年，並以故事型短影音《這一站，青春》傳達古蹟也能承載青春足跡與同行回憶。

網站內容需保留企劃書中的核心用語與資料：主要目標客群、AIO 分析、4 位 19–20 歲青年訪談、SWOT、競爭者比較分數、場域差異化優勢、故事大綱及組員分工。不可自行增加市場比例、調查結論或未經確認的場域資訊。

## 一、網站規劃與定位 Prompt

```text
請扮演熟悉 UI/UX、前端網頁設計與 SEO 的網站設計師。
我正在製作「這一站，青春」行銷影展專題網站。
核心場域為臺中驛鐵道文化園區，主要目標客群為 18～24 歲青年。
請依企劃書規劃首頁、影展介紹、故事與場景、行銷企劃及製作團隊五個頁面。
請建立清楚的導覽列、側邊欄、頁面導覽及資訊架構。
```

## 二、視覺風格與版面 Prompt

```text
請以復古車站與青春電影感作為網站設計方向，
使用深墨綠、暖米白及復古金色。
版面加入適當留白、細線分隔、文字層次及影像區塊。
使用 CSS Grid 與 Flexbox 建立版面，
兼顧桌機、平板及手機瀏覽。
```

## 三、HTML 與 CSS 建置 Prompt

```text
請使用 HTML5 語意化標籤建立五個網站頁面。
所有頁面共用一致的頂部導覽列、側邊欄及頁尾。
CSS 拆分放在 css 資料夾，圖片放在 images 資料夾，
JavaScript 放在 js 資料夾。
請保持檔案路徑正確，方便上傳至 InfinityFree 或部署至 Vercel。
```

## 四、內容整理 Prompt

```text
請依照《甲四_這一站，青春_期末企劃書》整理網站文字。
行銷頁需包含產業現況、消費需求、競爭者分析、SWOT、
市場區隔、18–24 歲目標客群、AIO、功能與情感需求、
4 位青年訪談摘要、競爭者比較評分及市場定位。
故事頁需呈現成年女主角翻閱手機相簿、高中好友走訪臺中文學館及臺中驛、
購買吊飾紀念，以及多年後因相同吊飾重逢的情節。
團隊頁需依企劃書姓名與職務整理。
不要捏造企劃書沒有的數據。
```

## 五、SEO、RWD 與除錯 Prompt

```text
請為每個頁面加入獨立的 title、Meta Description、keywords、
author、robots 及 Open Graph。
請檢查桌機、平板與手機的排版，
確認導覽列、側欄、表格、圖片及文字不會溢出。
請檢查所有 HTML、CSS、JavaScript 與圖片路徑。
```

## 六、資料正確性檢查

- 主要目標客群為 18–24 歲青年，包含學生及初入職場者。
- 訪談對象共 4 位，年齡為 19–20 歲；訪談結果僅作初步質性參考。
- 競爭者為宮原眼科、審計新村及臺中州廳。
- 比較指標為鐵道主題辨識度、活動多元性、參與體驗性及交通便利性。
- 競爭者評分採企劃書內 1–5 分設定，不應包裝成客觀官方評鑑。
- 情感溝通概念為「青春回憶的載體與情感轉運站」。
- 場域定位為「結合鐵道歷史與多元生活體驗的城市文化場域」。
- Slogan 為「古蹟留下歷史，我們留下足跡。」
