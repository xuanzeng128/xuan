## 程式用途
本程式會整理聚餐名稱與餐費文字，將餐費轉成數字、將人數文字轉成整數，再計算 10% 服務費、扣除折價券後的應付總額、每人分攤費用，並判斷是否超過每人 300 元預算。

## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
`"4"` 是文字（`str`），不是數字。文字不能直接拿來做本題的除法計算，因此要先用 `int()` 轉成整數 `4`，才能計算每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
如果先扣折價券，服務費會是 `(1,200 - 100) × 10% = 110` 元，應付總額為 `1,200 - 100 + 110 = 1,210` 元。這和題目規定的 `1,220` 元不同，因為題目要求服務費必須先依原始餐費 1,200 元計算，再扣除折價券。
