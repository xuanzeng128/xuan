# 《這一站，青春》行銷影展網站

依據《甲四_這一站，青春_期末企劃書》製作的大二影展專題介紹網站。

## 網站內容
- 首頁：影展主視覺、創作概念與導覽
- 影展介紹：企劃緣起、創作理念、廣告精神與目標
- 故事與場景：短影音故事大綱、臺中驛鐵道文化園區與故事場景
- 行銷企劃：目標客群、AIO、消費者洞察、SWOT 與市場定位
- 製作團隊：組員名單、工作分工與文案理念

## 技術
HTML5 語意結構、CSS Grid、RWD、SEO meta、Open Graph、少量原生 JavaScript。
CSS 分拆於 `css/`；圖片置於 `images/`；互動程式置於 `js/`。

## 正式繳交前
請以團隊實際拍攝照片、正式影片連結及授權素材替換示意插畫；確認各頁資訊及連結無誤。
